# Original Pause audio

These six audio files are synthesized from mathematical waveforms and seeded noise by `scripts/generate_audio.py`. They contain no sampled recordings or third-party material. The source and resulting audio are provided under CC0-1.0 (public domain dedication); no attribution is required.

Rain, ocean, and ambient are looping backgrounds. Bell, bowl, and chime are nine-second PCM WAVs also suitable for bundled local notification sounds. Regenerate using Python 3 with its standard library.
